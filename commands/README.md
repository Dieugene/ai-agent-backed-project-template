# Working commands (Claude Code slash-commands)

Переиспользуемые **slash-команды** Claude Code, наработанные в практике
agent-backed workspace. Каждый `.md` здесь — готовый промпт-шаблон: кладёшь
файл в каталог команд Claude Code, и он вызывается как `/<имя-файла>`.

## Установка

Скопировать нужный `.md` в каталог команд Claude Code:

- **Глобально (для всех проектов):** `~/.claude/commands/<name>.md`
- **Только для одного репозитория:** `<repo>/.claude/commands/<name>.md`

После этого команда доступна как `/<name>` в сессии. Содержимое `.md` —
это инструкция, которую Claude получает при вызове команды (не код).

## Команды

| Команда | Назначение |
|---------|------------|
| [`handoff-myself.md`](handoff-myself.md) | Сохранить «handoff самому себе» перед `/compact` или закрытием сессии: выжать из контекста неочевидное и открытые хвосты в один файл и сослаться на него из своего `CLAUDE.md`, чтобы перечитать при возобновлении. Поддерживает мульти-агентные пулы: имя/место handoff-файла привязаны к `AGENT_OWNER` и к ближайшему «своему» `CLAUDE.md`, чтобы агенты разных проектов не писали в общий файл. |

### Почему handoff-myself полезна

Координация агента **с самим собой через время** (через `/compact`,
перезапуск сессии). Тот же приём описан как паттерн в
[Pool Communication §8 «Per-owner handoff»](../docs/pool-communication.md) —
команда автоматизирует его дисциплину: всегда писать в **тот же** файл (не
плодить новые), фокусироваться на неочевидном, явно перечислять файлы для
перечитывания.
